# Runebase World Guide

The Runebase World Guide: how the Runebase games work (the Discord bot today, the Runebase World web app later), published with GitHub Pages.

These pages are generated from `docs/player-guide` in the bot's repository
(`npm run guide:publish`): edit them there. Every rule in them is proven by the
bot's tests, and the numbers come from the game data.
