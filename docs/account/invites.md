# ✉️ Invites

When someone joins the Runebase server through your invite (invites count only there, see <span class="gi-m">🌍&nbsp;[Realms](realms.md)</span>), you earn **25 experience** once they reach **100 <span class="gi-m">🗣️&nbsp;[chat points](chat-points.md)</span>**. Once per invited member; the reward is posted as **✉️ Invite Reward** (paid all the same when the server has no experience channel to post it in).

Discord doesn't tell the bot which invite someone used: it compares every invite's use count before and after the join. A join counts for you only when exactly one invite's count went up, by one, and it's yours: two people joining through different invites at the same moment, a join through the server's own link or Discovery, or an invite made while the bot was restarting credits nobody. A member is counted once, the first time they join. No reward goes to a player banned from the bot, nor for a banned member's join (also after the ban is lifted).
