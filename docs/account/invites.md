# ✉️ Invites

When someone joins the Runebase server through your invite (invites count only there, see <span class="gi-m">🌍&nbsp;[Realms](realms.md)</span>), you earn **25 experience** once they reach **100 <span class="gi-m">🗣️&nbsp;[chat points](chat-points.md)</span>**. Once per invited member; the reward is posted as **✉️ Invite Reward**.
