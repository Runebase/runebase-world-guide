# ![Swift Disarmament](../../../../assets/icons/crown-skill/swift-disarmament.webp){ .gi .gi-title width="64" height="64" loading="lazy" } Swift Disarmament

**Where to play:** Discord
{ .where-to-play }

- **Tree:** [Defensive skills](index.md) (for the Crown: they work while you hold it)
- **Kind:** passive: always on
- **Learn it from:** your rank 18
- **Needs first:** no other skill
- **Opens:** no other skill

> In the game: Reduces the cooldown of Defuse, allowing you to nullify Doomseed debuffs more rapidly.

## What it does

Defuse waits 900 seconds minus 30 a rank before you can use it again.

The Crown's own skills and runes: [holding the Crown](../../holding-the-crown.md); the minute round: [the round and the reign](../../round-and-reign.md).
