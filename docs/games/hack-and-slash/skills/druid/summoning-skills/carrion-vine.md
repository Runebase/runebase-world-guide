# Carrion Vine

**Where to play:** Discord
{ .where-to-play }

- **Class:** [Druid](../../../classes/druid.md)
- **Tree:** [Summoning Skills](index.md)
- **Kind:** a passive skill
- **Learn it from:** level 12 (your rank)
- **Needs first:** [Poison Creeper](poison-creeper.md)
- **Opens:** [Solar Creeper](solar-creeper.md)
- **Weapon:** any

> In the game: Adds Direct Poison Damage to Poison Creeper

## How it works

- It's always on: nothing to select, no mana.
