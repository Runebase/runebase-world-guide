# Skills

**Where to play:** Discord
{ .where-to-play }

Each class has three skill trees.

- **Skill points:** one per level, and the default Throw skill holds one, so a level-3 character has 2 to spend. You can't spend more than you have, and a skill takes at most 20 points.
- A skill needs its level and the skills listed before it (each skill's page says which).
- **Reset:** 5 <span class="gi-m">![](../../../assets/icons/item/grilled-sardines-with-sumac-yogurt-sauce.webp){ .gi .gi-mention width="20" height="20" loading="lazy" }&nbsp;[Grilled Sardines with Sumac Yogurt Sauce](../../../items/dishes.md#grilled-sardines-with-sumac-yogurt-sauce)</span> in total, whatever the points; it leaves only the base skills.
- **Using skills:** on the battle screen you pick a main and a secondary skill; each is a button with its mana cost ("<span class="gi-m">![](../../../assets/icons/skill/warrior/bonk.webp){ .gi .gi-mention width="20" height="20" loading="lazy" }&nbsp;[Bonk](warrior/combat-skills/bonk.md)</span> [💙2]"), charged once when used. A skill you can't use (not enough mana, not in the right shape, or without the weapon it needs, like <span class="gi-m">![](../../../assets/icons/skill/hunter/magic-arrow.webp){ .gi .gi-mention width="20" height="20" loading="lazy" }&nbsp;[Magic Arrow](hunter/bow-and-crossbow-skills/magic-arrow.md)</span> without a bow) shows as **Attack** and makes the regular attack instead, for free.
- **What a skill does at each rank is what its skill screen shows**: the battle uses the same numbers.

## Free resets at the release

Every character that existed before this release gets **one free attribute reset and one free skill reset**: the reset screen says **free**, nothing is spent, and it's used once (also on a double click). After it, resets cost their steaks and sardines again. New characters don't get them.
