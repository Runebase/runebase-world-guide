**Where to play:** Discord
{ .where-to-play }

- **Slot:** ring
- **When attacking:** Gain Assault Fortification (Block Buff) +1%
- **When defending:** Counter-Attack Chance +0.25%
- **Crafting cost:** 50 [Wood Scrap](../../../items/materials.md#wood-scrap), 200 [Metal Scrap](../../../items/materials.md#metal-scrap), 50 [Leather Scrap](../../../items/materials.md#leather-scrap)

## How gear works

You craft it with scrap from the heist gear menu (exactly the scrap listed) and wear one item per slot. An attacking bonus works only when you attack, a defending bonus when you defend (and when you're counter-attacked). Without Tactical Shift your neutral set counts both ways; with it, the offensive set attacks and the defensive set defends. Every slot adds up. More: [heist gear](index.md).

Other items for the ring slot: [Baldur's Gleaming Band](baldurs-gleaming-band.md), [Skadi's Frostbite Ward](skadis-frostbite-ward.md).
