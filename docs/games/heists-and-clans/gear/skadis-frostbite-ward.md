# ![Skadi's Frostbite Ward](../../../assets/icons/heist-gear/skadis-frostbite-ward.webp){ .gi .gi-title width="64" height="64" loading="lazy" } Skadi's Frostbite Ward

**Where to play:** Discord
{ .where-to-play }

- **Slot:** ring
- **When attacking:** Gain Retribution Fury (Counter Attack Buff) +1%
- **When defending:** Block Chance +0.25%
- **Crafting cost:** 25 [Wood Scrap](../../../items/materials.md#wood-scrap), 200 [Metal Scrap](../../../items/materials.md#metal-scrap), 75 [Leather Scrap](../../../items/materials.md#leather-scrap)

## How gear works

You craft it with scrap from the heist gear menu (exactly the scrap listed) and wear one item per slot. An attacking bonus works only when you attack, a defending bonus when you defend (and when you're counter-attacked). Without Tactical Shift your neutral set counts both ways; with it, the offensive set attacks and the defensive set defends. Every slot adds up. More: [heist gear](index.md).

Other items for the ring slot: [Baldur's Gleaming Band](baldurs-gleaming-band.md), [Einherjar's Wrathful Loop](einherjars-wrathful-loop.md).
