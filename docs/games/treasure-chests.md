# Treasure chests

**Where to play:** Discord
{ .where-to-play }

A quick game of luck: open treasure chests with keys.

`/treasurechest` in the treasure chest channel shows the chest. **Loot treasure chest**, then pick a key: the chest spends exactly that key and **rolls its key's prize table three times** (credits, RUNES, items, experience). A chest whose three rolls all miss pays **1 experience**.

- Without that key, or with the tipbot offline, nothing is spent.
- One key clicked on two chest buttons at once opens one chest and spends the key once.
- Better keys pay the same prizes at the same chances, the same amount or more:

**Getting keys:** key piles in the channels ([Piles and the key hunt](piles-and-key-hunt.md)), the **Treasure Forge** building (a [Bronze](../items/keys-and-cards.md#bronze-key), [Silver](../items/keys-and-cards.md#silver-key) or [Gold Key](../items/keys-and-cards.md#gold-key) for 1, 2 or 3 [Metal Scrap](../items/materials.md#metal-scrap); [Buildings](../account/buildings.md)), heists, scratch cards and Loot Reels. Keys are kept in your pouch, which has room for a limited number per pouch level.

## Tips

- A [Gold Key](../items/keys-and-cards.md#gold-key) pays about twice what a [Bronze Key](../items/keys-and-cards.md#bronze-key) pays, at the same odds.
