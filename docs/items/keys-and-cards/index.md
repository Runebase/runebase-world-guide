# ![Bronze Key](../../assets/icons/item/bronze-key.webp){ .gi .gi-title width="64" height="64" loading="lazy" } Keys and cards

What some games take to play: <span class="gi-m">![](../../assets/icons/item/gold-key.webp){ .gi .gi-mention width="20" height="20" loading="lazy" }&nbsp;[treasure keys](treasure-keys.md)</span> open <span class="gi-m">![](../../assets/icons/emoji/bronzekey.webp){ .gi .gi-mention width="20" height="20" loading="lazy" }&nbsp;[treasure chests](../../games/treasure-chests.md)</span> (and each one found counts on the [key hunt](../../games/piles-and-key-hunt.md#key-hunt)); <span class="gi-m">![](../../assets/icons/item/mystery-card.webp){ .gi .gi-mention width="20" height="20" loading="lazy" }&nbsp;[Mystery Cards](cards-and-relics.md#mystery-card)</span> scratch <span class="gi-m">![](../../assets/icons/emoji/goldcard.webp){ .gi .gi-mention width="20" height="20" loading="lazy" }&nbsp;[scratch cards](../../games/scratch-cards.md)</span>, <span class="gi-m">![](../../assets/icons/item/runes-pattern-card.webp){ .gi .gi-mention width="20" height="20" loading="lazy" }&nbsp;[Runes Pattern Cards](cards-and-relics.md#runes-pattern-card)</span> play <span class="gi-m">🃏&nbsp;[Runes Pattern](../../games/runes-pattern.md)</span>, and <span class="gi-m">![](../../assets/icons/item/chaos-relic.webp){ .gi .gi-mention width="20" height="20" loading="lazy" }&nbsp;[Chaos Relics](cards-and-relics.md#chaos-relic)</span> pay for <span class="gi-m">🗡️&nbsp;[attacks on the Crown](../../games/crown-of-chaos/attacking.md)</span>.
