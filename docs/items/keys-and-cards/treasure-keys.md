# ![Gold Key](../../assets/icons/item/gold-key.webp){ .gi .gi-title width="64" height="64" loading="lazy" } Treasure keys

Treasure keys open <span class="gi-m">![](../../assets/icons/emoji/bronzekey.webp){ .gi .gi-mention width="20" height="20" loading="lazy" }&nbsp;[treasure chests](../../games/treasure-chests.md)</span>, and each one found counts on the [key hunt](../../games/piles-and-key-hunt.md#key-hunt).

## ![Bronze Key](../../assets/icons/item/bronze-key.webp){ .gi .gi-entry width="32" height="32" loading="lazy" } Bronze Key

- **Where you get it:** made by the <span class="gi-m">![](../../assets/icons/building/treasure-forge.webp){ .gi .gi-mention width="20" height="20" loading="lazy" }&nbsp;[Treasure Forge](../../account/buildings.md#what-each-building-does)</span>; collected from <span class="gi-m">🗝️&nbsp;[piles](../../games/piles-and-key-hunt.md#piles)</span> in the channels; a prize of <span class="gi-m">![](../../assets/icons/game/heists.webp){ .gi .gi-mention width="20" height="20" loading="lazy" }&nbsp;[heists](../../games/heists-and-clans/attacks-and-defence/index.md#the-heists-prize)</span>, <span class="gi-m">🎰&nbsp;[Loot Reels](../../games/loot-reels.md)</span>, <span class="gi-m">![](../../assets/icons/emoji/goldcard.webp){ .gi .gi-mention width="20" height="20" loading="lazy" }&nbsp;[scratch cards](../../games/scratch-cards.md)</span>, [quest rewards](../../account/quests.md#every-quest).
- **Treasure chests:** opens a treasure chest ([more](../../games/treasure-chests.md)).
- **Key hunt:** each one found scores 1 on the monthly key hunt ladder ([more](../../games/piles-and-key-hunt.md#key-hunt)).
